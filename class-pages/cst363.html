Database Design Lab | Mini-Commerce ER Diagram

Designed a relational database for a small e-commerce ordering system. The lab focused on identifying entities, attributes, relationships, cardinalities, and database constraints based on a set of business requirements.

The database included Customers, Addresses, Orders, Products, Order Items, and Payments. I modeled one-to-many, one-to-one, and optional relationships while using an Order Item associative entity to store product quantity and the unit price at the time of purchase.

I created the ER diagram using MermaidJS and converted the design into PostgreSQL tables using the Mermaid JS ERD to SQL extension in Visual Studio Code.
